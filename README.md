# Hybrid Enterprise IT Support & Systems Administration Lab

A hands-on IT administration lab built to demonstrate practical skills for IT Support, Help Desk, Desktop Support, IT Analyst, IT Administrator, and Systems Administrator roles.

This project simulates a hybrid business IT environment and documents real-world workflows involving identity management, endpoint administration, Windows Server, Active Directory, ticketing, automation, troubleshooting, security baseline documentation, and disaster recovery planning.

---

## Fictional Company

**BlancoTech Solutions** is a simulated 75-person hybrid company with five departments:

- Human Resources
- Finance
- Sales
- Operations
- Information Technology

---

## What This Lab Demonstrates

- Microsoft 365 administration: users, groups, licenses, Exchange, Teams, SharePoint, and OneDrive
- Microsoft Entra ID: identity management, MFA, groups, access control, and Conditional Access
- Microsoft Intune: device compliance, configuration profiles, app deployment, and endpoint remediation
- Windows Server 2022: Active Directory Domain Services, DNS, DHCP, and Group Policy
- GLPI ITSM: ticketing, SLA management, asset inventory, escalation, and knowledge base documentation
- PowerShell automation: user lifecycle tasks, reporting, endpoint diagnostics, and network checks
- Troubleshooting runbooks: structured diagnostic procedures for common IT issues
- Security baseline documentation: MFA, password policy, patching, incident response, and AD audit findings
- Backup and disaster recovery planning: RPO/RTO, restore procedures, and outage response
- Network documentation: IP schema, topology diagram, DNS/DHCP design, and VPN troubleshooting
