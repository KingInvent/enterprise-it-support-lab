# Resume and LinkedIn Project Packaging

## Overview

This document provides recruiter-facing wording for the Hybrid Enterprise IT Support and Systems Administration Lab.

The goal is to convert the technical project into clear resume bullets, LinkedIn project text, GitHub profile wording, and interview talking points.


Built and documented a hybrid enterprise IT support lab simulating a 75-user company environment with Active Directory, Group Policy, DNS, PowerShell automation, GLPI ticketing, troubleshooting runbooks, sample tickets, knowledge base articles, security baseline documentation, and disaster recovery planning.

## Interview Talking Points

## 1. Project Purpose

```text
I built this project to demonstrate practical IT support and systems administration skills in a realistic environment. Instead of only listing tools on my resume, I wanted to show how I would structure users, groups, policies, automation, tickets, runbooks, and documentation in a real support environment.
```

## 2. Active Directory

```text
I created a Windows Server Active Directory lab for a fictional 75-user company. I built an OU structure by department, created users and security groups, assigned group memberships, and documented the environment with screenshots and validation commands.
```

## 3. Group Policy

```text
I configured Group Policy controls for password and lockout standards, screen lock enforcement, USB storage restriction, and mapped drive deployment. These policies demonstrate basic security and user environment management.
```

## 4. PowerShell Automation

```text
I wrote PowerShell scripts for common IT tasks, including new hire onboarding, employee offboarding, AD user reporting, group membership reporting, account lockout checks, and network connectivity testing. Each script was documented and validated with screenshot evidence.
```

## 5. GLPI Ticketing

```text
I deployed GLPI locally with Docker Compose and MariaDB to simulate an ITSM ticketing system. I created ticket categories, sample assets, and realistic tickets for onboarding, account lockout, VPN failure, mapped drive issues, and offboarding.
```

## 6. Troubleshooting Runbooks

```text
I created 10 troubleshooting runbooks for common IT support issues, including account lockouts, VPN problems, mapped drive issues, DNS resolution, printer offline, Outlook mailbox problems, MFA issues, slow computers, and phishing reports.
```

## 7. Knowledge Base Articles

```text
I also created user-facing knowledge base articles so the project shows both technical troubleshooting and user communication. These include articles for password reset, VPN connection, company drive access, MFA setup, and phishing email reporting.
```

## 8. Security Baseline

```text
I documented a security baseline covering password policy, account lockout policy, screen lock, USB restrictions, group-based access, least privilege, MFA support, phishing response, offboarding, and PowerShell audit scripts.
```

## 9. Backup and Disaster Recovery

```text
I created a backup and disaster recovery plan that explains how the project would recover GitHub documentation, Active Directory configuration, DNS, Group Policy, GLPI, Docker files, screenshots, and PowerShell scripts.
```

## 10. What I Learned

```text
This project helped me connect individual IT tools into a full support workflow. I practiced not only setup and troubleshooting, but also documentation, ticket writing, escalation logic, user communication, security awareness, and recovery planning.
```
