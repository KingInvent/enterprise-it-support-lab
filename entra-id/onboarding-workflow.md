# New Hire Onboarding Workflow

## Objective

Document the process for onboarding a new employee into the simulated company IT environment.

## Scenario

A new Sales employee, Jordan Lee, is joining BlancoTech Solutions. The IT team needs to create the user account, assign licenses, add group memberships, prepare endpoint access, and document the completed request in the ticketing system.

## Required Information

Before creating the account, IT must confirm:

- Full name
- Job title
- Department
- Manager
- Start date
- Work location
- Required applications
- Required mailbox or shared mailbox access
- Required Teams or SharePoint access
- Hardware assignment

## Standard Username Format

    first.last@blancotechsolutions.com

## Example User

| Field | Value |
|---|---|
| Name | Jordan Lee |
| Department | Sales |
| Job Title | Sales Representative |
| Manager | Maria Gonzalez |
| Email | jordan.lee@blancotechsolutions.com |
| Groups | Sales, All Employees |
| Required Apps | Outlook, Teams, OneDrive, CRM web app |
| Hardware | Windows 11 laptop, dock, monitor |

## Onboarding Steps

1. Create user account in Microsoft 365 / Entra ID.
2. Assign the correct Microsoft 365 license.
3. Add the user to department-based security groups.
4. Add the user to required Microsoft 365 groups or Teams.
5. Require MFA registration.
6. Assign hardware asset.
7. Prepare or enroll Windows endpoint.
8. Confirm access to Outlook, Teams, OneDrive, and SharePoint.
9. Document all completed work in the ticketing system.
10. Notify the hiring manager that onboarding is complete.

## Validation Checklist

- [ ] User account created
- [ ] License assigned
- [ ] MFA required
- [ ] Department group membership confirmed
- [ ] Microsoft 365 group membership confirmed
- [ ] Teams access confirmed
- [ ] SharePoint access confirmed
- [ ] OneDrive available
- [ ] Hardware assigned
- [ ] Ticket updated
- [ ] Hiring manager notified

## Example Ticket Note

Created Microsoft 365 user account for Jordan Lee in the Sales department. Assigned Microsoft 365 license, added user to Sales and All Employees groups, required MFA registration, assigned Windows 11 laptop asset, and documented access requirements for Outlook, Teams, OneDrive, and SharePoint. Ticket resolved after validation checklist was completed.

## Escalation Criteria

Escalate to a system administrator if:

- Required license is unavailable
- User cannot complete MFA registration
- SharePoint or Teams access does not apply after group assignment
- Endpoint enrollment fails
- Required business application access needs admin approval
